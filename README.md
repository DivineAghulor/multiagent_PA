# multiagent_pa

Personal-assistant multi-agent system (LangChain/LangGraph). See
[`implementation-plan.md`](implementation-plan.md) for the phased plan and
[`SETUP.md`](SETUP.md) to get a local environment running.

The web interface (FastAPI in [`api/`](api/), Next.js in [`web/`](web/)) is
specified in [`docs/webapp-requirements.md`](docs/webapp-requirements.md);
[`SETUP.md`](SETUP.md) has the two commands that start it.
